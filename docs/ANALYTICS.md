# Правила аналитики (ТЗ §17)

| Вопрос ТЗ | Правило |
|---|---|
| События | `page_view` (загрузка публичной страницы), `booking_click` (кнопка «Записаться»), `booking_started` (открытие формы записи), `booking_completed` (подтверждение OTP; фиксирует сервер), `booking_cancelled` (отмена подтверждённой записи; фиксирует сервер). События `booking_completed` и `booking_cancelled` от браузера игнорируются, чтобы их нельзя было подделать |
| Уникальный посетитель | Дневной HMAC-SHA256(секрет, дата в часовом поясе филиала, IP, User-Agent, филиал). Без cookies и без хранения IP. В пределах суток один браузер одного устройства — один посетитель |
| Уникальные за неделю/месяц | Сумма дневных уникальных (задокументированное приближение, решение D-19). Точная дедупликация за длинные периоды потребовала бы постоянного идентификатора и согласия на cookies |
| Повторные визиты | Повторные просмотры в тот же день увеличивают «просмотры», но не «уникальных». На следующий день посетитель считается заново |
| Источники трафика | `utm_source`, иначе домен referrer (кроме собственного домена), иначе `direct` |
| Период атрибуции | Last-touch в пределах сессии браузера: UTM сохраняются в sessionStorage и обновляются новыми UTM в URL; сессия истекает после 30 минут бездействия. Запись получает UTM из сессии, в которой начато оформление (D-20) |
| Внутренние просмотры | Исключаются: просмотры сотрудниками своей организации и суперадмином (по сессии) и предпросмотр черновика (вне публичного маршрута) |
| Боты | Исключаются по User-Agent (библиотека `isbot`) и при пустом User-Agent |
| Cookies | Аналитические cookies не используются, баннер согласия не требуется. sessionStorage нужен только для атрибуции внутри вкладки |
| Конверсия | `успешные записи / уникальные посетители` и `успешные записи / клики «Записаться»`, в процентах |
| Популярные услуги и специалисты | По записям, созданным в периоде (статусы confirmed/completed) |
| Динамика | Агрегаты по дням (`analytics_daily_aggregates`), сгруппированные по дню, неделе (с понедельника) или месяцу |
| Доступ | Только сотрудники организации с правом `analytics.view` по своим филиалам |

Агрегация идемпотентна (upsert) и выполняется воркером каждые 10 минут за последние двое суток, а также при запросе отчёта за запрошенный период.
