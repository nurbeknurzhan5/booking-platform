## Аудит 2026-11-26

Полная проверка проекта на ошибки и безопасность. Решения заказчика: «Тестовый телефон» — только явным флагом (D-44); на GitHub не отправлять, Docker и Actions исправить, но не запускать.

**Безопасность (исправлено, на каждый дефект — тест, падающий на старом коде):**
- XSS на встроенной карте `/embed/map`: подпись из адреса и название филиала выводятся только текстом; сообщения `2gis-set`/`2gis-pick` — только от своего окна и только конечные координаты. CSP сайта: `script-src-attr 'none'`, `Cross-Origin-Opener-Policy`.
- Чужие записи по непроверенному телефону: кабинет `/me`, лист ожидания и подтверждение резерва привязывают записи к профилю только при подтверждённом номере; номер, указанный сотруднику без подтверждения, освобождается в пользу клиента, подтвердившего его кодом (D-52).
- «Тестовый телефон» был публичным при `APP_ENV` по умолчанию: теперь только `DEV_INBOX_ENABLED=true` / `NEXT_PUBLIC_DEV_INBOX_ENABLED=true`, в production API не запускается (fail-closed, D-44).
- Токены в журналах: API маскирует сегменты пути после `manage`, `waitlist-offers`, `confirm` и не пишет заголовки; Caddy — `format filter` (адрес, `Referer`, `Location`, учётные заголовки). Страницы с токеном — `Referrer-Policy: no-referrer`.
- Ссылки управления записью в outbox шифруются и стираются после отправки; DLQ-повтор только для подтверждения и переноса (D-48).
- Переводы: BRANCH_ADMIN — только страницы и специалисты своих филиалов, уровень организации — владелец.
- MFA: не больше 10 неверных кодов за 15 мин, каждый код TOTP принимается один раз (миграция `20261125100000_mfa_replay_protection`); при входе прежняя сессия браузера отзывается.
- Подмена IP для rate limit через `X-Forwarded-For`: Next.js пропускает заголовок клиента как есть, поэтому `TRUST_PROXY=1` только за Caddy (production), `0` локально, в CI/E2E и Codespaces (по умолчанию тоже `0`); API доверяет только внутренним адресам и не больше `TRUST_PROXY` хопов (D-54). Проверено через настоящий rewrite Next.js (изолированный стенд: сайт :3400 → API :4400): при `1` — 25×200 без 429, при `0` — 20×200 и 429; E2E-проверка в `security.spec.ts` падает при `1` и проходит при `0`.
- Тело запроса больше 1 МБ давало 500 со стеком в журнале: теперь 413 `PAYLOAD_TOO_LARGE`, битый JSON — 400 с русским сообщением, неподдерживаемая кодировка — 415, журнал warn без стека (D-55).
- Обезличивание оставляло ПД в резервах, OTP, outbox, тестовом телефоне и аудите: теперь стираются, append-only журналы меняются только в транзакции `app.pii_erasure` (миграция `20261125000000_pii_erasure`, D-45), исключения с основанием — в SECURITY.md.
- Мелкие: Swagger в production выключен, строгая CSP API (D-53); `canEdit` суперадмина без MFA; карточка клиента для BRANCH_ADMIN; `MediaService.urlsFor` по организации; тег GCM 16 байт; идемпотентность в области действующего лица (D-49); пути запросов сайта к API через `apiPath` (кодирование, запрет `..`); не-UUID в адресах кабинета → 404, `userId` → 400.

**Корректность:** несуществующие даты (`2026-02-31`) → 400, годы 1900–2999 (D-46); периоды подписок и акций сравниваются как моменты времени, а не строки (в схемах и сервисах); копейка промокода при бесплатной последней позиции; сообщение о переносе ведёт гостя на страницу управления (D-47); устаревшее время при параллельных переносе и отмене; гонка первой вставки настроек записи; выбор пересекающихся особых часов; `quote.durationMinutes` с буфером; публичный `/health` кеширует статистику outbox (D-51); `DeprecationWarning` pg — запросы в транзакции последовательно (D-50).

**Инфраструктура:** `npm run db:reset:test` работает (`apps/api/scripts/reset-test-db.ts`); Dockerfile без несуществующего корневого tsconfig, `openssl` для Prisma, свои `.dockerignore`; job `docker` в CI (**не проверено: нужен прогон CI**); `effect` через `overrides` — `npm audit --omit=dev`: 0 уязвимостей; тестовые артефакты `apps/api/.test-storage` сняты с индекса; Caddy без `trusted_proxies`; `npm run typecheck` проверяет и тесты API (`tsconfig.test.json`, включая `scripts`, `prisma`) и E2E.
